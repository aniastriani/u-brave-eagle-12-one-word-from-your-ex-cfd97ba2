One word, the word my ex would use to describe me: **voicemail**. She never picked up — she let it ring, then listened to the message weeks later at 2x speed while doing something else, and still replied "sorry, just saw this". A message left, unanswered, archived by someone who meant to get back to it and never did. That is the whole relationship in one word.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The program writes exactly one word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure Python standard library, no dependencies, deterministic.
